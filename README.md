# Книжная полка — SPA на React

Учебное SPA-приложение с каталогом книг, глобальной корзиной, переключением темы, маршрутизацией и демонстрационным входом.

## Требования
- Node.js 18+ (рекомендуется актуальная LTS-версия)
- npm

## Запуск
1. Распакуйте архив.
2. Откройте терминал в папке `book-store-spa`.
3. Установите зависимости:
   ```bash
   npm install
   ```
4. Запустите приложение:
   ```bash
   npm run dev
   ```
5. Откройте URL, который покажет Vite (обычно `http://localhost:5173`).

Проверка production-сборки:
```bash
npm run build
```

## Функциональность
- Каталог из 6 книг одной тематики.
- Добавление книг в корзину; количество одинаковых книг объединяется.
- Изменение количества, удаление позиции и очистка корзины.
- Автоматический пересчёт суммы заказа.
- Глобальная корзина на Context API и `useReducer`.
- Светлая и тёмная тема через Context API.
- Навигация без перезагрузки с `BrowserRouter`, `Routes`, `Route` и `NavLink`; активный пункт меню выделяется.
- Демонстрационная форма входа. После заполнения непустых логина и пароля происходит переход на `/dashboard`. Защищённая страница кабинета перенаправляет неавторизованного пользователя на `/login`.

## Структура
```text
book-store-spa/
├── index.html
├── package.json
├── README.md
└── src/
    ├── App.jsx
    ├── main.jsx
    ├── styles.css
    ├── data/
    │   └── books.js
    └── state/
        └── AppProviders.jsx
```

Это демонстрационный учебный проект: авторизация не связана с сервером, а данные корзины хранятся в памяти приложения и сбрасываются после перезагрузки.
